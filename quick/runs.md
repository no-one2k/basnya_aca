# Журнал прогонов

Правила:

1. Файлы промптов, входов, выходов и данных не перезаписываются: новая версия =
   новое имя (`prompts/v2.md`, `top_v2.jsonl`).
2. Первая строка каждого `prompts/vN.md` — что изменилось против прошлой версии.
3. После каждого прогона в таблицу дописывается одна строка, старые строки не правятся.
4. Ожидаемые ответы демо лежат в `inputs/<вход>_expected.md`, промпт их не читает.
5. Новая сессия начинает с чтения этого файла и последних строк таблицы.
