# Вопросы к пользователю

Правила:

1. Агент, которому посреди шага нужно решение пользователя, не ждёт и не угадывает
   молча: дописывает вопрос в раздел «Вопросы» по шаблону ниже, продолжает
   с умолчанием или с тем, что от вопроса не зависит, и в конце отчёта напоминает,
   сколько вопросов открыто.
2. Пользователь отвечает строкой «Ответ: …» под вопросом и меняет `[ ]` на `[x]`.
3. Каждый бриф начинается с чтения этого файла: если ответ расходится с умолчанием,
   агент переделывает затронутое и дописывает к вопросу «применено в шаге N».
4. Записи не удаляются.

Шаблон вопроса:

```text
- [ ] Шаг N: <вопрос>. Контекст: <1–2 строки>. По умолчанию: <вариант>
```

Отвеченный вопрос:

```text
- [x] Шаг N: <вопрос>. Контекст: <1–2 строки>. По умолчанию: <вариант>
  Ответ: <ответ пользователя>
```
