Task: for each snippet in the input file, pick 3–5 quotes or memes from the data file that fit it by meaning and tone.
Work dir: /home/noone/work/vibe/basnya_aca/quick/ (all paths below are relative to it).
Parameters given at launch: INPUT = inputs/<name>.md (snippets under headings "## 1", "## 2", …); DATA = top.jsonl unless told otherwise.
Read only INPUT and DATA. Do not read inputs/*_expected.md, quotes.jsonl, or anything in outputs/ or prompts/.

1. Read DATA in full with line numbers, in consecutive chunks: `cat -n top.jsonl | sed -n '1,50p'`, then '51,100p', … to the last line (`wc -l` first). If a chunk is cut off, re-read it in smaller parts. Do not grep for keywords to find candidates: every line must be seen. Each line is JSON: text, work, section, author, url, source, kind (quote | meme | meme_quote), backlinks. For kind=meme, text is the meme's name.
2. For each snippet choose 3–5 records that fit by meaning and tone (fewer only if fewer fit). Never pad with weak matches.
3. Hard rule: quote text is only a verbatim copy of the text field (JSON escapes like \" shown as plain quotes). Never write a quote from memory.
4. Check every chosen record before answering: `grep -cF '<substring>' top.jsonl`, where the substring is 30–50 consecutive characters copied from text as is (the whole text if shorter; the meme name for kind=meme), containing no ' " or \ characters. Show the count. If it is 0, drop the record.
5. If a fitting quote comes to mind that is not in DATA, name only its work in the line "нет в корпусе: …", never its text.
6. If nothing fits a snippet, write only "ничего не подходит" under its heading (plus "нет в корпусе" if any). A forced match is worse than none.

Output, in Russian, saved to outputs/<YYYY-MM-DD>_v1_<name>.md (today's date, name = INPUT file name without .md, e.g. 2026-10-22_v1_demo_01.md):

```
## N
1. строка <line number> — «<text verbatim>»
   - источник: <work>, <section>   (kind=meme: Lurkmore: <page>; kind=meme_quote: <author, if any>, Lurkmore: <page>)
   - ссылка: <url from the record>
   - почему подходит: <one sentence>
   - вплетено: <the snippet, or its key sentence, rewritten with the quote woven in>
   - grep -cF '<substring>' top.jsonl → <count>
2. …
нет в корпусе: <work>, <work>
```

Omit the "нет в корпусе" line if empty. Do not overwrite existing files.
Finally append one row to runs.md without touching other lines:
`| <YYYY-MM-DD> | v1 | top.jsonl | <name> | outputs/<file>.md | — |`
